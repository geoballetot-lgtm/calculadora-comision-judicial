Reglas aplicadas

141 y 241 se clasifican como castigo. Los demás módulos se tratan como vigente.

La antigüedad judicial selecciona inicialmente la ruta de menos o mayor de un año. Si existe número de cuota, se asigna la ruta de cuota refinanciada/fraccionada.

Puedes ajustar la ruta de cada pago para atender una excepción antes de validar el resultado.
